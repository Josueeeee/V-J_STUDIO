# V&J Estudio — Landing interactiva

Página única (`index.html`, todo incluido en el archivo, sin compilación): efectos de clic y sonido opcional,
capturas reales del V&J Lab con visor, demos web en vivo y selector de idioma ES/EN.

- Ver localmente: `python -m http.server 8124` dentro de esta carpeta y abrir `http://localhost:8124`.
- Apps del Lab sin publicar: cuando tengan URL pública, pegarla en `LIVE_PROJECTS[...].url` dentro del HTML.
- Textos nuevos: agregar su traducción al diccionario `EN` del final del archivo, o se quedarán en español con la página en inglés.

## Publicación

El repositorio remoto es `https://github.com/Josueeeee/V-J_STUDIO.git`. La rama pública es `main`.
